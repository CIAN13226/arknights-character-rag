# 可露希尔

## 基本信息
- 名称：可露希尔
- 星级：6
- 职业：先锋
- 分支：战术家
- 站位：远程位
- 标签：费用回复 控场
- 特性：可以在攻击范围内选择一次 战术点来召唤援军，自身攻击援军阻挡的敌人时攻击力提升至150%
- 所属势力：罗德岛

## 属性
- 再部署 70s  部署费用 13→15  阻挡数 1  攻击速度 1.0s
- 精英0 1级：生命 788 / 攻击 202 / 防御 46 / 法抗 0
- 精英0 满级（50级）：生命 1126 / 攻击 298 / 防御 77 / 法抗 0
- 精英1 满级（80级）：生命 1444 / 攻击 393 / 防御 110 / 法抗 0
- 精英2 满级（90级）：生命 1762 / 攻击 480 / 防御 131 / 法抗 0
- 信赖加成：攻击 +60 / 防御 +20
- 模组：给自己的小奖杯（max_hp:180;atk:30;def:25）

## 天赋
- 天赋1「精准投放」
-     （精英0）：可以在战术点召唤指挥中心协助作战，其被击败后会在15秒后自动刷新；战术点效果范围随携带技能变化，效果范围内的友方单位视为自身的援军
- 天赋2「极限调度」
-     （精英2）：携带可露希尔时，部署费用下限降低3，【罗德岛】干员攻击力+4%
-     （精英2 X模组2级）：携带可露希尔时，部署费用下限降低4，【罗德岛】干员攻击力+6%
-     （精英2 X模组3级）：携带可露希尔时，部署费用下限降低5，【罗德岛】干员攻击力+8%

# 死芒

## 基本信息
- 名称：死芒
- 星级：6
- 职业：术师
- 分支：塑灵术师
- 站位：远程位
- 标签：召唤 输出
- 特性：攻击造成 法术伤害，可以通过击倒敌人生成 召唤物，可攻击到自身 召唤物阻挡的敌人
- 所属势力：维多利亚 › 塔拉

## 属性
- 再部署 70s  部署费用 19→21  阻挡数 1  攻击速度 1.6s
- 精英0 1级：生命 799 / 攻击 309 / 防御 54 / 法抗 10
- 精英0 满级（50级）：生命 1111 / 攻击 424 / 防御 81 / 法抗 10
- 精英1 满级（80级）：生命 1443 / 攻击 531 / 防御 110 / 法抗 15
- 精英2 满级（90级）：生命 1924 / 攻击 633 / 防御 133 / 法抗 20
- 信赖加成：攻击 +45 / 防御 +45
- 模组：未处理的遗产（max_hp:200;atk:55）

## 天赋
- 天赋1「复燃」
-     （精英0）：攻击范围内敌人被击倒时生成一个悲叹的仆役，最多召唤2个，若无法再次召唤则使一个悲叹的仆役升级（提升生命、攻击和防御）
(升级后：生命值+50%，攻击力+50%，防御力+20%)
-     （精英1）：攻击范围内敌人被击倒时生成一个悲叹的仆役，最多召唤3个，若无法再次召唤则使一个悲叹的仆役升级（提升阻挡数、生命、攻击和防御）
(升级后：生命值+50%，攻击力+50%，防御力+20%，阻挡数+1)
-     （精英2）：攻击范围内敌人被击倒时生成一个悲叹的仆役，最多召唤3个，若无法再次召唤则使一个悲叹的仆役升级（提升阻挡数与更多的生命、攻击和防御）
(升级后：生命值+100%，攻击力+100%，防御力+40%，阻挡数+1)
-     （精英2 X模组2级）：攻击范围内敌人被击倒时在10秒内自身攻击力+15%，并在攻击范围内生成一个悲叹的仆役，最多召唤3个，若无法再次召唤则使一个悲叹的仆役升级（提升阻挡数与更多的生命、攻击和防御）
(升级后：生命值+100%，攻击力+100%，防御力+40%，阻挡数+1)
-     （精英2 X模组3级）：自身和召唤物攻击范围内敌人被击倒时在10秒内自身攻击力+25%，并在攻击范围内生成一个悲叹的仆役，最多召唤3个，若无法再次召唤则使一个悲叹的仆役升级（提升阻挡数与更多的生命、攻击和防御）
(升级后：生命值+100%，攻击力+100%，防御力+40%，阻挡数+1)
- 天赋2「回光黯淡」
-     （精英2）：自身和召唤物攻击生命低于50%的敌人时攻击力提升至140%

开启：立刻重新召唤所有悲叹的仆役，若场上没有悲叹的仆役存在则召唤1个（初始6，消耗17）
-     专精三：被动：每个悲叹的仆役生成和升级时对周围所有敌人造成相当于死芒攻击力 450%的法术伤害
开启：立刻重新召唤所有悲叹的仆役，若场上没有悲叹的仆役存在则召唤1个（初始8，消耗13）
- 技能名：折朽（自动回复 / 手动触发）
-     7级：令最多 2名攻击范围内的敌人陷入沉睡，每 0.5秒对目标造成相当于攻击力 130%的法术伤害；技能期间目标被击倒时额外召唤 2个悲叹的仆役（初始11，消耗22，持续12）
-     专精三：令最多 2名攻击范围内的敌人陷入沉睡，每 0.5秒对目标造成相当于攻击力 160%的法术伤害；技能期间目标被击倒时额外召唤 2个悲叹的仆役（初始14，消耗20，持续12）
- 技能名：冠死以冕（自动回复 / 手动触发）

-     专精三：被动：最多1名悲叹的仆役变为特殊形态，此形态下只能通过技能升级，最多升级6次
开启：立刻对范围内所有敌人造成攻击力 800%的法术伤害，之后消耗一个悲叹的仆役使特殊仆役升级并回复 20%生命（若悲叹的仆役已升级则翻倍），重复 3次（初始5，消耗16）

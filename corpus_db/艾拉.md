# 艾拉

## 基本信息
- 名称：艾拉
- 星级：6
- 职业：特种
- 分支：陷阱师
- 站位：远程位
- 标签：召唤 控场 输出
- 特性：可以使用陷阱来协助作战，但陷阱无法放置于 敌人已在的格子中
- 所属势力：彩虹小队

- 再部署 70s  部署费用 10→12  阻挡数 1  攻击速度 0.85s
- 精英0 1级：生命 696 / 攻击 270 / 防御 72 / 法抗 0

- 信赖加成：攻击 +80
- 模组：社会期望背包（atk:60;def:30）

## 天赋
- 天赋1「雷鸣地雷」
-     （——）：可以使用1个雷鸣地雷（最多拥有2个），经过周围的第一个敌人会触发其效果，撤退时以自身为中心触发一次雷鸣地雷效果
-     （精英1）：可以使用2个雷鸣地雷（最多拥有3个），经过周围的第一个敌人会触发其效果，撤退时以自身为中心触发一次雷鸣地雷效果
-     （精英2）：可以使用3个雷鸣地雷（最多拥有4个），经过周围的第一个敌人会触发其效果，撤退时以自身为中心触发一次雷鸣地雷效果
- 天赋2「“正中靶心”」
-     （精英2）：攻击有30%几率造成相当于攻击力150%的物理伤害，对受到雷鸣地雷效果影响的目标必定触发
-     （精英2 Δ模组2级）：攻击有40%几率造成相当于攻击力160%的物理伤害，对受到雷鸣地雷效果影响的目标必定触发
-     （精英2 Δ模组3级）：攻击有50%几率造成相当于攻击力170%的物理伤害，对受到雷鸣地雷效果影响的目标必定触发

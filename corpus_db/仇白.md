# 仇白

## 基本信息
- 名称：仇白
- 星级：6
- 职业：近卫
- 分支：领主
- 站位：近战位
- 标签：输出 控场
- 特性：可以进行 远程攻击，但此时攻击力降低至80%
- 所属势力：炎

## 属性
- 再部署 70s  部署费用 18→20  阻挡数 2  攻击速度 1.3s
- 精英0 1级：生命 1041 / 攻击 299 / 防御 191 / 法抗 5
- 精英0 满级（50级）：生命 1488 / 攻击 447 / 防御 263 / 法抗 5
- 精英1 满级（80级）：生命 1959 / 攻击 581 / 防御 333 / 法抗 10
- 精英2 满级（90级）：生命 2480 / 攻击 718 / 防御 402 / 法抗 10
- 信赖加成：攻击 +50 / 防御 +50
- 模组：雪浸过的斗笠（atk:55;def:45;attack_speed:7）；欲雪时（max_hp:280;atk:50;attack_speed:7）

## 天赋
- 天赋1「入隙」
-     （精英1）：攻击处于停顿、束缚的敌人时，额外造成相当于攻击力25%的法术伤害
-     （精英2）：攻击处于停顿、束缚的敌人时，额外造成相当于攻击力40%的法术伤害
-     （精英2 X模组2级）：攻击处于停顿、束缚的敌人时，额外造成相当于攻击力45%的法术伤害，目标同时处于停顿和束缚时该伤害提升至原本的1.1倍
-     （精英2 X模组3级）：攻击处于停顿、束缚的敌人时，额外造成相当于攻击力45%的法术伤害，目标同时处于停顿和束缚时该伤害提升至原本的1.2倍
- 天赋2「落英」
-     （精英2）：攻击时有20%的几率使目标束缚1.5秒
-     （精英2 Y模组2级）：攻击时有23%的几率使目标束缚1.5秒，首次命中敌人时提升至100%且束缚时间提升至3秒
-     （精英2 Y模组3级）：攻击时有25%的几率使目标束缚1.5秒，首次命中敌人时提升至100%且束缚时间提升至3秒

## 技能（7级 / 专精三）
- 技能名：留羽（攻击回复 / 自动触发）
-     7级：下次攻击使目标束缚 2.5秒，该次束缚结束时对目标和附近的所有敌人造成相当于攻击力 240%的法术伤害（初始0，消耗5）
-     专精三：下次攻击使目标束缚 3秒，该次束缚结束时对目标和附近的所有敌人造成相当于攻击力 300%的法术伤害（初始0，消耗4）
- 技能名：承影（攻击回复 / 手动触发）
-     7级：对前方范围内的地面敌人造成攻击力 240%的法术伤害；攻击范围 改变，攻击力 +90%，攻击范围内的地面敌人停顿；技能结束时对范围内的地面敌人造成攻击力 240%的物理伤害（初始4，消耗12，持续5）
-     专精三：对前方范围内的地面敌人造成攻击力 300%的法术伤害；攻击范围 改变，攻击力 +140%，攻击范围内的地面敌人停顿；技能结束时对范围内的地面敌人造成攻击力 300%的物理伤害（初始5，消耗10，持续5）
- 技能名：问雪（自动回复 / 手动触发）
-     7级：攻击范围 扩大，攻击力 +40%，伤害类型变为法术，额外攻击2个目标，远程攻击不再降低伤害，每次攻击使自身攻击速度 +13（最多叠加 6次）（初始38，消耗58，持续30）
-     专精三：攻击范围 扩大，攻击力 +55%，伤害类型变为法术，额外攻击2个目标，第一天赋的伤害提升至 2倍，远程攻击不再降低伤害，每次攻击使自身攻击速度 +13（最多叠加 8次）（初始45，消耗55，持续30）

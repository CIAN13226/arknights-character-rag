# 棘刺

## 基本信息
- 名称：棘刺
- 星级：6
- 职业：近卫
- 分支：领主
- 站位：近战位
- 标签：输出 防护
- 特性：可以进行 远程攻击，但此时攻击力降低至80%
- 所属势力：伊比利亚

## 属性
- 再部署 70s  部署费用 18→20  阻挡数 2  攻击速度 1.3s
- 精英0 1级：生命 1096 / 攻击 296 / 防御 191 / 法抗 5
- 精英0 满级（50级）：生命 1567 / 攻击 442 / 防御 263 / 法抗 5
- 精英1 满级（80级）：生命 2063 / 攻击 575 / 防御 333 / 法抗 10
- 精英2 满级（90级）：生命 2612 / 攻击 711 / 防御 402 / 法抗 10
- 信赖加成：攻击 +30 / 防御 +70
- 模组：“盐与沙”（max_hp:260;atk:55;attack_speed:7）；沙蚀（max_hp:150;atk:75;attack_speed:7）

# 夜半

## 基本信息
- 名称：夜半
- 星级：5
- 职业：先锋
- 分支：战术家
- 站位：远程位
- 标签：费用回复 控场
- 特性：可以在攻击范围内选择一次 战术点来召唤援军，自身攻击援军阻挡的敌人时攻击力提升至150%
- 所属势力：雷姆必拓

- 再部署 70s  部署费用 12→14  阻挡数 1  攻击速度 1.0s
- 精英0 1级：生命 726 / 攻击 187 / 防御 46 / 法抗 0
- 精英0 满级（50级）：生命 1038 / 攻击 275 / 防御 78 / 法抗 0
- 精英1 满级（70级）：生命 1332 / 攻击 362 / 防御 112 / 法抗 0
- 精英2 满级（80级）：生命 1625 / 攻击 442 / 防御 133 / 法抗 0
- 信赖加成：攻击 +60
- 模组：星星与瞌睡虫（max_hp:150;atk:20;def:20）

## 技能（7级 / 专精三）
- 技能名：半醒（自动回复 / 手动触发）
-     7级：立刻获得 11点部署费用，眠兽进入休眠，期间每秒恢复 13%最大生命；眠兽受到伤害时醒来，攻击力40% +40%，攻击速度40% +40%，持续 10秒（初始14，消耗28，持续10）
-     专精三：立刻获得 11点部署费用，眠兽进入休眠，期间每秒恢复 14%最大生命；眠兽受到伤害时醒来，攻击力55% +55%，攻击速度55% +55%，持续 10秒（初始17，消耗25，持续10）
- 技能名：安眠（自动回复 / 手动触发）
-     7级：立即使战术点周围的所有地面敌人陷入 5秒沉睡并获得 4点部署费用； 5秒内眠兽的攻击变为群体法术攻击，攻击沉睡的目标时攻击力提升至 150%
 可充能2次（初始10，消耗17）
-     专精三：立即使战术点周围的所有地面敌人陷入 6秒沉睡并获得 4点部署费用； 6秒内眠兽的攻击变为群体法术攻击，攻击沉睡的目标时攻击力提升至 210%
 可充能2次（初始10，消耗16）
